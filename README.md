# Lineup

Lineup is a Moddy service. It uses the same design system as moddy.app.

- [`design-kit/`](design-kit/): the Moddy design kit (CSS, theme, fonts, web
  components, demo). Start with [`design-kit/README.md`](design-kit/README.md)
  and the rules in [`design-kit/DESIGN-SYSTEM.md`](design-kit/DESIGN-SYSTEM.md).

The kit comes from `design-kit/` in [moddy-app/website](https://github.com/moddy-app/website).
When the look changes there, copy the change here.
